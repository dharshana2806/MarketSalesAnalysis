# Supermarket Sales Analysis

## Project Overview
This project analyzes 500 supermarket sales transactions using Python and data analytics. It examines products, branches, cities, categories, customer types, gender, payment methods, ratings, quantities, and sales trends.

## Problem Statement
The objective is to convert supermarket transaction data into clear business insights that can support inventory, branch, customer, payment, and service decisions.

## Dataset
**Dataset:** Provided project dataset  
**Rows:** 500  
**Columns:** 13

### Dataset Columns
- Invoice ID

- City
- Customer Type
- Gender
- Product
- Category
- Quantity

## How to Run
1. Install Python.
2. Keep the CSV file in the same folder as the notebook.
3. Install dependencies:

```bash
pip install -r requirements.txt
```

4. Open Jupyter Notebook.
5. Open `Sakthivel_Dharshana_SupermarketSalesAnalysis.ipynb`.
6. Run all cells from top to bottom.
